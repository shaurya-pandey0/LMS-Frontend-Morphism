# 🚀 LifeTrack — Future Scope & Proposed Architectures

This directory contains architectural designs, proposed enhancements, and scaling blueprints that are **planned for future milestones** but are **not part of the current active production build**.

---

## Index of Future Features & Designs

| File | Proposed Feature | Current Production Reality |
|---|---|---|
| [`vector-db-turbovec.md`](vector-db-turbovec.md) | **Local RAG & Vector Database**<br>Embed journal entries locally into 4-bit TurboVec / NumPy vector stores for semantic retrieval. | **Aggregate Context Prompting**<br>Chat and insights currently operate on trusted aggregate numerical windows generated by Spring Boot (`/api/ai-context`). |

---

## Why These Are Categorized as Future Scope

1. **Simplicity & Resource Efficiency:** The current single-VM setup is 100% stable, cost-optimized (₹0 out-of-pocket with credits), and handles full traffic via Docker Compose and Nginx on port 443.
2. **Context Window vs. RAG:** For the current dataset sizes (habits, daily logs, expenses), structured JSON aggregation provides faster, deterministic, and hallucination-free prompts without needing vector embedding pipelines.
